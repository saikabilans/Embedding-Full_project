## Features

### Task 1 – Embeddings

Creates vector embeddings from text using:

```text
all-MiniLM-L6-v2
```

The model generates 384-dimensional vectors.

---

### Task 2 – Chunking

Documents are divided into smaller chunks so that they can be converted into embeddings and searched efficiently.

---

### Task 3 – Vector Database

The generated embeddings are stored in Qdrant.

Qdrant is used for vector similarity search.

The Qdrant dashboard can be opened at:

```text
http://localhost:6333/dashboard
```

---

### Task 4 – Semantic Search API

A FastAPI application provides a `/search` endpoint.

The API accepts a search query, creates an embedding for the query, searches Qdrant, and returns the most similar results.

# Installation

## 1. Create Virtual Environment

Open the project folder in VS Code terminal.

Run:

```powershell
python -m venv venv
```

Activate the environment:

```powershell
.\venv\Scripts\Activate.ps1
```

If the environment is already activated, you will see:

```text
(venv)
```

in the terminal.

---

## 2. Install Requirements

Run:

```powershell
pip install -r requirements.txt
```

If required packages are missing, install them with:

```powershell
pip install fastapi uvicorn python-dotenv requests sentence-transformers
```

---

# Environment Configuration

Create a `.env` file in the project root.

Example:

```env
OPENROUTER_API_KEY=your_openrouter_api_key_here
OPENROUTER_BASE_URL=https://openrouter.ai/api/v1

OPENROUTER_EMBEDDING_MODEL=openai/test-embedding-3-small

LOCAL_EMBEDDING_MODEL=all-MiniLM-L6-v2

QDRANT_URL=http://localhost:6333
QDRANT_COLLECTION=week6_task1

API_KEY=my-secret-key-sai245150
```

### Important

Do not upload the real API keys to GitHub.

The `.env` file should be included in `.gitignore`.

# Semantic Search

Open:

```text
POST /search
```

Click:

```text
Try it out
```

Enter the API key in the:

```text
x-api-key
```

header.

The API key must match the value configured in `.env`.

Example:

```text
my-secret-key-sai245150
```

Then enter the request body:

```json
{
  "query": "What is artificial intelligence?",
  "top_k": 5,
  "doc_type": "string",
  "min_score": 0
}
```

Click:

```text
Execute
```

---

# Example Search Response

A successful response will look similar to:

```json
{
  "query": "What is artificial intelligence?",
  "top_k": 5,
  "results": [
    {
      "id": 1,
      "score": 0.72,
      "payload": {
        "text": "Artificial intelligence is..."
      }
    }
  ],
  "result_count": 1,
  "search_time_ms": 35.2
}
```

The exact results and similarity scores depend on the data stored in Qdrant.
